# 💖 Romantic Date Proposal & VIP Boarding Pass Invitation

An ultra-modern, interactive, and aesthetic **"Will you go on a date with me?"** web application with rich micro-animations, playful runaway button physics, romantic Web Audio API synthesizer, 4-step date planner, golden ticket boarding pass generator, secret love letter, and an **Admin Response Backup & Webhook Notification Engine**.

> **Crafted with 💖 by Vikul Tyagi**

---

## ✨ Features

- 💌 **3D Romantic Envelope & Wax Seal**: Interactive opening animation with romantic audio chimes.
- 🥰 **Runaway "NO" Button**: Escapes cursor/touch coordinates with funny rejection evasion quotes and whoosh sounds, while the "YES" button grows exponentially.
- 🎉 **Full-Screen Confetti Cannon**: Celebratory burst with hearts, stars, ribbons, and romantic fanfare chords.
- 🍝 **4-Step Date Planner**:
  1. Cuisine & Food selection
  2. Romantic Adventures & Activities
  3. Rendezvous Date & Time selection
  4. Dress Code aesthetic & optional sweet wishlist note
- 🎫 **Luxury VIP Date Boarding Pass**:
  - Downloadable high-res **PNG Ticket Snapshot** for Instagram Stories.
  - One-click **WhatsApp Confirmation** message auto-sender.
- 🔒 **Secret Admin Response Dashboard**:
  - Secure PIN protection (Default PIN: `2026`).
  - View all submitted date plans with timestamps, selected food, activity, date, time, vibe, and personal notes.
  - One-click **Export to CSV / Excel**.
  - **Instant Push Alerts**: Supports Discord Webhook, Telegram Bot, or Formspree integration so you get an instant mobile notification the second she accepts!
- 🎨 **4 Romantic Themes**: Romantic Rose, Midnight Romance, Dreamy Lavender, Sunset Peach.
- ⚙️ **Shareable Link Engine**: Automatically generates customized URLs (e.g. `?to=Princess&from=Vikul&phone=919876543210&theme=rose`).

## 🚀 Quick Start (Local)

1. Open `index.html` in any modern web browser.
2. Or start the built-in Node server:
   ```bash
   node server.js
   ```
3. Open `http://localhost:3000` in your browser.
